# Configurator Intelligence Hub

Configurator Intelligence Hub is a Next.js web application for exploring, filtering and benchmarking product configurators worldwide.

The website uses an enhanced dataset generated by a Python pipeline and imported into a local SQLite database through Prisma.

## Features

- Product configurator explorer
- Filters by industry, country, status and visualization type
- Overall Configurator Score
- Configurator detail pages
- Industry rankings
- Animated premium UI
- Local SQLite database
- Self-hostable with Cloudflare Tunnel

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- SQLite
- Framer Motion
- shadcn/ui
- lucide-react
